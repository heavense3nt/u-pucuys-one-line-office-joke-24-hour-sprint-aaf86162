One short joke about office life — a single line, 69 characters — written by a
deterministic program to `/output/entry.txt` for make.fun's "One-Line Office
Joke: 24-Hour Sprint" bounty.

> HR says we're a family here, so I asked for a raise and got grounded.

The setup is the line every office worker has heard ("we're a family here");
the punchline takes that family logic literally — ask for a raise, get
grounded like a kid. One sentence, one line, no explanation needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the joke, byte for byte, to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(69 characters, UTF-8, no trailing newline). Node 22+ runs `main.ts`
directly; the program uses only the standard library and has no other
dependencies, so every run produces the identical file.
